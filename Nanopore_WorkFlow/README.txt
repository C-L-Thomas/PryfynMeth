# Running PryfynMeth with Nanopore data

This tool is compatile with Nanopore sequencing. To generate data in the right format, you can use Nanopore's [Modkit](https://github.com/nanoporetech/modkit) tool. An example script for a loop of this can be found here [this](https://github.com/C-L-Thomas/PryfynMeth/blob/main/Nanopore_WorkFlow/Example_Modkit.sh). With this loop, both stranded and unstranded data are compatible with PryfynMeth.
